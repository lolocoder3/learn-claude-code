# Task Manager Functionality Test

Please test the task manager features in the order below, and report the results after each step:

## Step 1: Create Tasks
Use the `task_create` tool to create 4 tasks:
- Task 1: subject="Implement user authentication system", description="Add login, registration, and permission management"
- Task 2: subject="Design database architecture", description="Create user and permission tables"
- Task 3: subject="Write API endpoints", description="Implement REST API"
- Task 4: subject="Frontend login page", description="Create login interface"

## Step 2: List All Tasks
Use the `task_list` tool to view all tasks and verify:
- All 4 tasks have been created
- Each task's ID, subject, and description are displayed correctly

## Step 3: View Task Details
Use `task_get` to view full details for individual tasks:
- task_get(task_id=1)
- task_get(task_id=2)
- Verify the returned JSON contains all fields (id, subject, description, status, etc.)

## Step 4: Create More Tasks
Create 2 additional tasks to test continuous task creation:
- Task 5: subject="Write unit tests", description="Write test cases for core features"
- Task 6: subject="Deploy to production", description="Configure server and deploy application"

## Step 5: List All Tasks Again
Use `task_list` to confirm there are now 6 tasks

## Step 6: Verify Data Persistence
Check the `.tasks/` directory to verify:
- Each task is saved as an independent JSON file
- File naming format is task_<id>.json
- File contents include complete task information

## Step 7: View Specific Task Details
Randomly select a few task IDs and use `task_get` to verify data integrity

---
**Verification Points:**
✓ task_create correctly creates tasks and returns JSON
✓ task_list displays a concise summary of all tasks
✓ task_get returns complete task details
