# Task Manager 核心功能测试

请按照以下步骤测试 TaskManager 的核心功能：

## 第1步：创建基础任务
使用 `task_create` 工具创建3个基础任务：
1. 主题："设计系统架构"，描述："设计整体系统架构"
2. 主题："开发用户模块"，描述："实现用户注册登录功能"
3. 主题："部署到生产环境"，描述："配置服务器并部署"

## 第2步：基本操作验证
1. 使用 `task_list` 查看所有任务，验证3个任务都已创建
2. 使用 `task_get` 查看任务1的详细信息，验证JSON包含所有字段

## 第3步：依赖关系测试
使用 `task_update` 设置依赖关系：
1. 让任务2依赖于任务1：addBlockedBy=[1]
2. 让任务3依赖于任务2：addBlockedBy=[2]

验证双向依赖：
1. 获取任务1详情，验证 blocks 包含任务2
2. 获取任务2详情，验证 blockedBy 包含任务1，blocks 包含任务3
3. 获取任务3详情，验证 blockedBy 包含任务2

## 第4步：状态更新与依赖清理
1. 将任务1状态更新为 "completed"
   - 验证任务2的 blockedBy 中移除了任务1
2. 将任务2状态更新为 "completed"
   - 验证任务3的 blockedBy 中移除了任务2

## 第5步：blocks 依赖关系测试
1. 创建任务4：主题："编写文档"，描述："编写用户手册"
2. 让任务3阻塞任务4：addBlocks=[4]
3. 验证任务4的 blockedBy 自动包含任务3
4. 将任务3状态更新为 "completed"
   - 验证任务4的 blockedBy 移除了任务3

## 第6步：错误处理测试
1. 尝试获取不存在的任务ID（如999）
2. 尝试更新任务状态为无效值（如"invalid_status"）

## 第7步：数据持久化验证
检查 `.tasks/` 目录：
1. 验证每个任务都保存为 task_<id>.json 文件
2. 验证文件内容包含完整的任务信息

## 验证要点：
✓ task_create 正确创建任务
✓ task_list 显示任务摘要
✓ task_get 返回完整详情
✓ task_update 正确更新状态和依赖
✓ 依赖关系双向更新正确
✓ 任务完成时自动清理依赖
✓ 数据持久化正常工作
✓ 错误处理机制正常
