Task Manager 功能测试

请按顺序测试 task manager 的各项功能，并在每个步骤后报告结果：

步骤 1：创建 3 个任务

使用 task_create 工具创建 3 个任务：
    - 任务 1：subject = "实现用户登录功能"，description = "支持邮箱和密码登录"
    - 任务 2：subject = "实现用户注册功能"，description = "支持邮箱注册，发送验证邮件"
    - 任务 3：subject = "编写单元测试"，description = "为登录和注册功能编写测试"

步骤 2：列出所有任务

使用 task_list 工具查看所有任务，确认：
    - 3 个任务都已创建
    - 每个任务的 ID、主题、描述都正确显示中文（无乱码）

步骤 3：获取任务 1 的详细信息

使用 task_get 工具，传入任务 1 的 ID，查看完整信息

步骤 4：更新任务 1 的描述

使用 task_update 工具，将任务 1 的描述更新为："支持邮箱、密码和第三方登录"

步骤 5：再次列出所有任务

使用 task_list 工具，确认任务 1 的描述已更新，其他任务未受影响
